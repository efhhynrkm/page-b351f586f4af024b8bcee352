使用场景

365VPN 适合把「偶尔需要出去」和「每天都要出去」放在同一套订阅里处理。下面按目的写，而不是按口号写。

资料、协作与开发

查阅海外文档、代码仓库、学术页和云控制台时，问题通常不是「能不能打开」，而是重定向、验证码与接口超时。用订阅配合带规则分流的客户端，可以把国内站点走直连、把指定域名走代理，减少整机全局代理带来的副作用。

远程桌面、设计协作和会议软件对链路稳定更敏感。建议在客户端里为常用域名单独建组，需要时再切，而不是把所有流量挤在同一条线路上。

出行、流媒体与娱乐

旅居或出差时，公共网络环境变化快，客户端最好支持快速切换节点和关闭连接。流媒体是否可播，取决于你所选套餐是否包含相应解锁能力，以套餐说明为准，本页不承诺具体片源或清晰度。

对延迟更在意的语音和对局，优先使用带游戏向或专线描述的套餐档位，并在客户端内固定一条你已经试过的线路，避免每次自动选择都重新抖动。

本页重点

客户端怎么选

365VPN 的机场订阅需要导入代理客户端后才能使用。官方下载入口集中在下方模块。先根据系统和习惯做判断，再点对应客户端，避免装完才发现缺少订阅字段或规则能力。

按系统

Windows / macOS / Linux：桌面端适合把订阅粘贴进客户端，开启系统代理或 TUN。若你需要按域名分流，选带规则配置的图形客户端，会比「仅全局开关」的工具更省事。

Android：注意后台省电策略，把客户端列入白名单，否则锁屏后隧道会被系统杀掉。权限只开代理所需项即可。

iOS：商店政策变化频繁，请确认设备上已有可用客户端，再导入 365VPN 订阅。本页不提供来路不明的安装包地址。

路由器：适合家里多设备共用出口，配置门槛更高，需要你会填写订阅或转换格式。不建议把路由器当作第一台试验设备。

按习惯

只想一键连接：选界面干净、订阅字段明确的客户端，连上后先访问一个你熟悉的海外站点做确认。

需要分流和策略组：选 Clash 系或同等规则客户端，把国内流量留在直连，把加速目标放进代理组。

多设备来回切换：先看套餐允许的同时在线数量，再在每台设备用同一订阅。设备更换时，在旧客户端里删除订阅，减少配置残留。

操作说明

  1. 对照套餐。打开本页套餐区，确认流量、设备和线路描述是否覆盖你的场景，再完成订阅。
  2. 复制订阅。在用户中心拿到订阅链接或二维码，只保存在你自己的密码管理器或笔记里，不要发到群聊。
  3. 安装客户端。回到客户端一节，按系统打开官方下载入口，安装完成后先不要急着连。
  4. 导入并更新。在客户端的订阅栏粘贴链接，执行更新，确认节点列表出现后再选择线路。
  5. 验证访问。开启连接，打开一个需要加速的站点；同时试一个国内站点，确认分流没有把不该代理的流量带走。异常时先换节点、再检查系统时间与规则模式。

导入后建议

系统时间误差过大会导致握手失败，先确认日期时间自动同步。公司电脑若有安全软件拦截虚拟网卡，需要允许客户端的网络扩展。更换套餐后，在客户端里手动更新一次订阅，避免仍在使用旧配置。

不建议做的事

不要把同一订阅二维码发到公开相册；不要同时开两个会抢系统代理的客户端；不要在未确认来源的「加速器破解版」里填 365VPN 链接。

常见问题

365VPN 是机场还是一款独立 VPN 软件？

365VPN 以机场订阅为主：你购买的是可导入各类代理客户端的配置，而不是必须使用某一个固定商标的闭源 App。本页同时承担官网介绍、套餐入口和客户端下载导引。真正发起连接的，是你安装的那个客户端。

必须使用指定客户端才能连上吗？

不必须绑定唯一软件，但要用支持该订阅格式的客户端。不同系统可用工具不同，优先使用本页客户端模块给出的官方下载。若某款软件缺少订阅字段或无法更新节点，换回推荐列表中的客户端即可，不必反复重装系统。

订阅链接不小心泄露了怎么办？

立刻在用户中心重置或重新生成订阅，并在所有已导入的客户端里删除旧链接、改填新链接。不要把订阅当作可以转发的「分享码」。重置后，旧链接应停止拉取节点，未重置前则无法保证他人不能使用你的额度。

客户端显示已连接，但网页打不开或特别慢，先查什么？

按顺序排查：节点是否已更新、系统时间是否准确、当前是全局还是规则模式、是否有第二个代理软件抢占端口。然后换一条线路再试。浏览器若开了自己的代理扩展，会和系统代理叠在一起，先关掉扩展再判断 365VPN 本身是否工作。

多台电脑和手机一起用，会互相踢下线吗？

同时在线数量以你购买的套餐说明为准。超出后可能出现新设备挤掉旧设备、或无法握手的情况。家用建议把不常用的设备退出客户端或关闭开机自启；团队使用应单独规划设备清单，而不是把个人套餐填进所有同事的手机。

流量或有效期看不懂，去哪里核对？

以用户中心的剩余流量和到期时间为准，客户端里的统计往往只是本地估算。年付与月付的结算差异也以套餐模块和订单页的文字为准。流量耗尽后应升级或等待重置周期，而不是反复开关节点。

可以在路由器上使用 365VPN 吗？

可以尝试，前提是路由器固件能填写该订阅或完成格式转换。这属于进阶用法：出错时会影响全家设备，建议先在电脑客户端验证订阅有效，再迁移到路由。本页不提供针对某一型号的刷机教程，也不编造兼容列表。
